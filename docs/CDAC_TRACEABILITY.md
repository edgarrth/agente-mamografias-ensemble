# CDAC traceability — concise prototype mapping

The prototype adapts the 19 CDAC stages to pretrained-model integration rather than model training.

- Conception/ethics/literature: scope, research-only use, model selection and licenses.
- Data preparation/exploration/external data/preprocessing: explicit dataset acquisition, source manifests, four-view canonical format.
- Initial/benchmark/multiple models: three verified pretrained models; no training.
- Primary metrics/XAI/secondary metrics: Sensitivity, ROC-AUC, confusion matrix, official XAI artifacts and resource logging.
- Deployment/risk/operationalization/monitoring: Docker Compose, workspace, audit logs, model registry, failure evidence and reproducible reports.
